How it grows

One branch name.
Every repo. Same instant.

Define a workspace once — a group of repos that belong together. From then on, a single gv call fans that branch out across all of them.

Group your repos

grove_workspaces[fullstack]="frontend backend" — or skip it; any single repo is a workspace automatically.

Call it once

gv fullstack fix-auth fetches, resolves the branch (tracking a remote if it exists, creating it where it doesn't), and cuts a worktree in each repo.

Everything lands together

All worktrees live under one workspace directory, with each repo's .claude/skills and .cursor merged in — so agents see the whole workspace.

Open the session

grove opens a tmux session and runs your hooks — install deps, launch claude, lay out panes. Reopen later and your agent resumes where it left off.

The canopy

Small tool. Deep roots.

Everything you need to run several branches — and several agents — in parallel without tripping over yourself.

Multi-repo workspaces

Group projects together and one command cuts worktrees across all of them — every repo on the same branch name, ready at once.

Smart branch resolution

Tracks an existing remote branch where it finds one and creates a fresh branch where it doesn't — so teammates' branches just check out everywhere.

Agent config, merged

Each repo's .claude/skills and .cursor are copied into the workspace root — names prefixed to avoid collisions — so your agent sees everything.

tmux, per workspace

One session per instance, auto-named grove/<ws>/<name> — which your terminal shows as the tab title, so a wall of tabs stays legible.

Interactive TUI

Type gv with no args for an fzf dashboard of every workspace — with a live branch tree and PR status in the preview pane.

Rollback on failure

If any worktree in the set fails to create, grove tears the whole thing back down — no half-planted workspace left behind.

Field guide

The whole vocabulary.

One verb — gv — does it all.

gv --help
everyday
gv
Open the interactive TUI dashboard
gv <workspace> <name>
Create or attach to a workspace instance
gv <workspace> <name> <cmd>
Run a command in the workspace (no tmux)
gv --ls
Show the branch tree for the current workspace
gv --list
List every workspace and instance
tending
gv --no-tmux <workspace> <name>
Create it, print its dir, skip tmux (for scripts & agents)
gv --rm [--force] <ws> <name>
Remove an instance (--force if it's dirty)
gv --kms [--force]
Remove the current workspace, from inside it
gv --home
cd to your projects directory
gv --update
Pull the latest grove (must be on main)
gv --help
Show the full usage guide
