What it does

Small tool. Whole workflow.

Run several branches — and several agents — in parallel without tripping over yourself.

Isolated by default — no contention

Every workspace is its own set of checkouts. Run five agents at once and none of them share a directory or a branch — no stomping on each other, no stashing, no “which agent touched this file?”

A workspace spans your repos

grove creates a worktree of every repo your feature touches — same branch, one folder. It’s a monorepo on demand: your agent works across all of them at once, without you ever having a real monorepo.

One agent sees every repo

grove pulls each repo’s skills and rules into the workspace, so a single agent understands the whole set — not one blinkered agent per checkout, each blind to the others.

Survives restarts & crashes

Reboot, a crash, a killed tmux — the workspace outlives its session. Reopen it and grove brings your agent back, resuming right where you left off.

  • Interactive TUI. Type gv for an fzf dashboard of every workspace — branch tree and PR status included.
  • One Zsh file, MIT. No app, no binary, no daemon — lightweight, open source, yours to read and hack.
  • Atomic setup. If any repo fails, grove rolls the whole workspace back — no half-planted mess to clean up.

Why not just run two agents?

Two agents, one checkout,
is a bad time.

Agents are isolated processes — but that means nothing if they share a working directory. Point two at the same repos and they overwrite each other’s files and fight over which branch is checked out. grove gives each its own checkout.

sharing a checkout agents collide
  1. one agent’s edits land on top of another’s, mid-task
  2. you git stash and switch branches just to see what the other one did
  3. only one branch is checked out — so only one feature moves at a time
  4. a half-finished refactor in the working tree breaks the other agent’s build
  5. a change spans two repos, and now you’re juggling four terminals
a grove each no contention 
❯ gv fullstack dark-mode
❯ gv fullstack emoji-reactions

Every feature gets its own isolated workspace — its own worktree of each repo, its own branch, its own session. They run side by side and never touch. Clean up with gv --rm, or gv --kms from inside.
